# Hyperspace for Apache Spark 3.5

This is a dedicated branch of Hyperspace targeting **Apache Spark 3.5.1** with **Scala 2.12.18** and **Java 17**.

## Overview

Hyperspace is an open source indexing subsystem for Apache Spark. This branch contains all features and sources optimized for Spark 3.5.x deployments, including:

- Delta Lake support (via delta-spark 3.3.2)
- Apache Iceberg support (via iceberg-spark3-runtime 0.11.1)
- Covering indexes
- Z-Order covering indexes
- Data skipping with sketches
- Index materialization and refresh
- Query planning integration

## Build Requirements

- **Java**: OpenJDK 17 or later
- **Scala**: 2.12.18
- **Spark**: 3.5.1 (provided at runtime)
- **sbt**: 1.11.7 or later

## Source Code Consolidation

This branch consolidates sources from multiple version-specific directories in the original multi-version project:

- Base sources: `src/main/scala/` (version-independent)
- Spark 3.x common: `src/main/scala-spark3/` (merged)
- Spark 3.5 specific: `src/main/scala-spark3.5/` (merged)

All sources are now in a single `src/main/scala` directory, eliminating version-specific directory prefixes and making the codebase cleaner and easier to maintain.

## Known Differences from Original Project

1. **No version matrix**: This branch targets only Spark 3.5.1
2. **No cross-version source directories**: All version-specific directories merged
3. **Java 17 target**: Original project targeted Java 1.8, this branch uses modern Java 17
4. **Simplified build.sbt**: Single-project configuration instead of multi-project aggregation
5. **Plain directories**: No symlinks or junction points in source tree

## Code Quality

Compilation produces warnings related to:

- Unused imports (standard code cleanup)
- Deprecated APIs in Spark (expected when using latest APIs)
- Dead code in some utility paths (handled gracefully)
- Implicit conversions (Java Optional to Scala Option conversions)

These are normal and expected; they do not affect functionality.
